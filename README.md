# 🧮 Python Calculator

A simple yet advanced calculator built with Python. It supports basic and advanced mathematical operations with input validation and error handling.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (\*)
- Division (/)
- Power (\*\*)
- Modulus (%)
- Square Root (√)
- Factorial (!)
- Input validation
- Error handling
- Interactive terminal menu

## 🛠️ Built With

- Python
- Math Module
- Functions
- Dictionaries
- Exception Handling

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Mostafa-Makram/Python_Calculator.git
```

### 2. Navigate to the Project Folder

```bash
cd Python_Calculator
```

### 3. Run the Program

```bash
python calculator.py
```
